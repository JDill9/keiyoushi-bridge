# keiyoushi-bridge

Auto-generated mirror that converts [keiyoushi's](https://github.com/keiyoushi/extensions)
new protobuf extension index (`index.pb`) back into the legacy `index.min.json` format,
so older Tachiyomi-lineage apps (Yokai/J2K style) can keep browsing and installing
extensions. English + multilingual extensions only. Refreshes every 6 hours.

Add this URL as your extension repo:

    https://raw.githubusercontent.com/JDill9/keiyoushi-bridge/repo/index.min.json

All credit for the extensions belongs to the keiyoushi project.
